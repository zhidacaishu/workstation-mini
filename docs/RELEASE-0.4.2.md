# Workstation Mini 0.4.2

- 新增重名卡片或删除已移走的卡片时，原有卡片保留各自的评分与到期时间；编辑期间若遇到外部修改会提示版本冲突。
- 恢复旧草稿并保存时，若原编辑器又保存了新版草稿，新版仍可在「历史与草稿」中找回；退出或切换资料库时会等待已开始的保存完成。
- 扫描意外中断后，启动应用或执行「重新扫描索引」可自动补齐反链；仅使用 CR 换行的旧笔记也能正确识别公式块之后的双链。首次升级会从笔记重建本机索引。
- 同步维护规则文件时增加文件类型校验；本地恢复会检查备份对 Git 对象库的依赖，若遇到无法随备份迁移的对象库将给出提示。
- 本次安装包同时包含 0.4.0 以来的复习轮次与侧栏位置保留、重复建卡确认，以及桌面弹窗、待办、图片粘贴与 Markdown 兼容性修复。

**安装与升级：** Windows x64 使用 `workstation-mini-0.4.2-setup.exe`，Apple Silicon Mac 使用 `workstation-mini-0.4.2-mac-arm64.dmg`；下载校验值见 `SHA256SUMS.txt`。可直接在现有资料库上手动升级，多台设备建议同步升级。

> `0.4.1` 标签的 Windows 回归验证未通过，正式安装包从 `0.4.2` 起发布。
