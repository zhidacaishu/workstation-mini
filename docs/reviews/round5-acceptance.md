## 修复

- Git 中止前同时收集工作区与暂存区的笔记、卡组和复习日志，包括已暂存的新文件。完整快照先以本机文件写入并 fsync，笔记与卡组写入历史；备份失败则保留 Git 冲突现场。中止后恢复复习日志失败时明确返回失败，并保留快照路径。
- 评分撤销改为追加 type=undo、undo_event_id 指向原评分的事件。读取、缓存与 FSRS 重放过滤作废评分，Git 合并/中止不再使其复活。原评分事件仍参与重试去重。各设备需使用支持撤销事件的新版本。
- 撤销尚未完成时禁用评分及暂停，包含快捷键；按原卡片位置恢复队列，并在离开页面时保护尚未完成的撤销。
- 编辑器增加引用续行、空引用结束；macOS 桌面测试保存快捷键使用 Cmd+S。
- 今日页复习入口与快速待办框增加 12px 间距。
- 历史对比的纯新增/纯删除也遵守 2000 行上限。

## 独立代码审查

独立只读子代理审查了全部未提交的后端、前端、模板、样式、Electron IPC 与设置、测试及发布元数据，主代理修复后由其再次复核。审查期间发现并修复：

- 多次粘图乱序返回导致替错占位符；上传期间保存可能写入失效链接。
- 复习日志超过合并上限时被当空内容；Git 符号链接可能使合并或中止恢复写到库外。
- 写入失败前直接截断日志；改为临时文件完整落盘后原子替换。
- 撤销响应丢失后的重试失败；快速重学时首次评分尚未返回导致计数错误。
- Git 字面反斜杠文件路径被映射成另一条路径；现在明确拒绝自动处理并保留现场。
- Markdown 未采用版本超限时可能跳过备份；保留手工合并结果时也备份两边版本。
- 卡片正面预览显示 Markdown/公式源码；改为服务端一致渲染。
- 两个 POSIX 非法跨平台文件名测试在 Windows 无法创建夹具；按平台跳过。冲突设置文案明确笔记/卡组与附件的保全范围。
