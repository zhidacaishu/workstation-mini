# 第五轮补丁应用与验收

2026-11-14。第五轮补丁已包含第四轮修改，故直接应用第五轮。随后按要求完成独立审查、修复与发布验收，最终发布版本为 v0.3.4。

## 修复

- **Git 中止前完整备份**：中止 Git 操作前同步收集工作区与暂存区的笔记、卡组及复习日志（含已暂存的新文件）。完整快照先以本机文件写入并执行 `fsync`，笔记与卡组同步写入历史；若备份失败则保留 Git 冲突现场。中止后若恢复复习日志失败，明确返回错误并保留快照路径。
- **评分撤销日志化**：评分撤销改为追加 `type=undo`、且 `undo_event_id` 指向原评分的事件。读取、缓存与 FSRS 重放会过滤已作废评分，Git 合并或中止操作不再使旧评分重新生效；原评分事件仍参与重试去重。各设备需统一升级至支持撤销事件的新版本。
- **撤销状态锁与队列保护**：撤销请求尚未完成时禁用评分及暂停操作（含快捷键）；撤销后按原卡片位置恢复队列，并在离开页面时保护尚未完成的撤销操作。
- **编辑器与桌面细节**：编辑器新增引用块续行及空引用回车结束；macOS 桌面测试保存快捷键改用 `Cmd+S`；今日页复习入口与快速待办框之间增加 12 px 间距；历史对比的纯新增或纯删除场景同样遵守 2000 行上限。

## 独立代码审查

独立只读子代理全面审查了全部未提交的后端、前端、模板、样式、Electron IPC 与设置、测试及发布元数据，主代理修复后再由其复核。审查期间发现并修复了以下问题：

- 多次粘贴图片乱序返回时替换错位占位符，且上传过程中保存可能写入失效链接。
- 复习日志超过合并上限时被视为空内容；Git 符号链接可能导致合并或中止恢复写入资料库外部。
- 写入失败前直接截断日志；改为先完整落盘临时文件再执行原子替换。
- 撤销响应丢失后的重试失败；快速重学时首次评分尚未返回导致统计计数不准。
- Git 字面反斜杠文件路径被误映射为另一条路径；现已明确拒绝自动处理并保留现场。
- Markdown 未采用版本超限时可能跳过备份；保留手工合并结果时改为同时备份双边版本。
- 卡片正面预览显示 Markdown 与公式源码；改为与服务端一致的排版渲染。
- 两个包含 POSIX 非法文件名的跨平台测试在 Windows 上无法创建夹具，已按平台跳过；同步冲突设置文案明确了笔记/卡组与附件各自的数据保全范围。

针对上述问题补充了回归测试，覆盖乱序上传、上传中保存与离开、撤销幂等性、重学统计、`ENOSPC` 写入失败、超限文件、符号链接、暂存及未暂存类型变更与字面路径。所有验证均使用临时 Git 资料库，不涉及真实笔记。

独立复核结论：70 项回归及追加的 8 项针对性回归全部通过，diff 格式检查通过，未发现已确认且未修复的发布阻碍。最终本机桌面回归 49/49 通过，macOS arm64 安装包构建成功；发布工作流继续在 Linux、Windows 与 macOS 上执行验证并测试打包后的桌面应用。

## Windows 等待根因与最终修复

定向诊断定位到根本原因：Electron 测试进程中的异步 `waitForFunction` 在返回 `handle=false` 时仍继续向后执行。Playwright 1.62.1 的谓词检查不等待 Promise，导致 `async` 谓词返回的 Promise 对象被立即判定为真值，随后才解析为 `false`。独立代理用最小 Electron 页面验证确认：`async () => false` 约 22 ms 即返回，`() => false` 则会正确等待至超时。

据此新增测试辅助函数 `waitForApi`，在 Node 侧等待每次 `fetch` 完成并校验响应后再决定是否重试，并替换了全部 8 处索引等待与 1 处冲突状态等待，同时补充了未就绪响应继续轮询及超时诊断回归。该问题属于测试等待语义缺陷，未据此改动产品 Git 状态逻辑。

原 v0.3.0 发布流程已取消，未生成公开安装包；最终版本更新为 v0.3.1，继续由真实 Windows / macOS 及打包测试进行验证。

## 目录键盘高亮修复

v0.3.1 在主分支的 Linux、macOS 与 Windows 均已通过，但发布流程中 macOS 的目录测试出现一次超时。独立代理先复现了“PageUp 后立即执行脚本滚动”可能相互覆盖的测试竞态；在等待键盘滚动完成后重测，进一步确认存在产品缺陷：当焦点停留在 `role="tab"` 上时，即便第二个标题已滚动至距顶 24 px 处，高亮仍锁定在末章，直至滚轮触发解锁后才恢复。

产品逻辑调整为仅跳过编辑控件及按钮/标签的 `Space` 激活；已被标签消费的导航键通过 `defaultPrevented` 保护，未消费的正文滚动键则释放章节锁。桌面回归测试明确将焦点置于目录标签，并等待 `PageUp` 的 `scrollend` 事件后再测试独立程序滚动，避免竞态掩盖高亮缺陷。此前两个未发布标签保留，最终版本更新为 v0.3.2。

## 原生过渡吞点击修复（v0.3.3）

v0.3.2 的正式发布流程在全平台通过并发布，但主分支重跑再次捕获复习入口点击后 URL 仍停留在卡组页的问题；诊断同时证实当时服务端队列非空且按钮存在。独立代理使用真实 Electron 最小页面将过渡时长延长至 3 s，确认在页面加载完成且原生过渡就绪后，对按钮和链接的坐标点击仍落在了 HTML 根节点上，目标元素未收到点击事件；分别为根过渡及全部过渡伪元素设置 `pointer-events: none` 亦无效。

在改用普通 `opacity` 入场动画的对照测试中，按钮点击与链接导航均恢复正常。因此产品移除原生 `navigation: auto` 快照过渡及相关脚本，改为工作区内容 140 ms 普通 CSS 淡入，侧栏保持静止，减少动态效果偏好依然生效。新增的桌面回归测试将动画延长至 3 s，在动画运行期间通过真实鼠标坐标操作复习入口、翻面与保存，不靠等待动画结束掩盖交互问题。最终补丁版本为 v0.3.3。

v0.3.3 最终本机验证结果：核心测试 606 项中 602 项通过、4 项平台跳过；macOS arm64 构建及签名结构检查通过；打包版桌面测试 50/50 通过（含新增动画期间真实点击回归）；独立代理完成最新差异复核。

## 日期早编辑与测试隔离（v0.3.4）

0.3.3 的动画期间真实点击回归已通过；主分支另捕获一处问题：计划页保存后立即编辑下一条日期时，保存入口处于隐藏状态。排查发现，测试满足新 DOM 业务条件并不等同于 `defer` 脚本已执行完毕，后续操作需等待页面 `load` 完成。独立代理同时基于真实 `plan.js` 的 VM 确认了产品边界问题：当服务端 `defaultValue` 为旧日期、而 `currentValue` 已是用户输入的新日期时，脚本初始化误将 `currentValue` 设为基线。

产品端改为以 `date.defaultValue` 作为服务端基线，初始化时立即渲染当前编辑状态，并同时监听 `input` 与 `change` 事件；同步补充无需额外触发 `input` 的初始化编辑保护回归。桌面测试在满足新 DOM 条件后等待完整 `load`，并在 `finally` 块中清理 409 与挂起请求拦截，避免单个用例失败污染后续用例。0.3.3 未发布安装包，最终版本定为 v0.3.4。

v0.3.4 最终本机验证结果：核心测试 607 项中 603 项通过、4 项平台跳过；开发版与打包版桌面测试均 50/50 通过；更新加载等待与拦截清理后的 18 项针对性交互测试全部通过，独立复核通过。
