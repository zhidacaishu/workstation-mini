## 修复

- Git 中止前同时收集工作区与暂存区的笔记、卡组和复习日志，包括已暂存的新文件。完整快照先以本机文件写入并 fsync，笔记与卡组写入历史；备份失败则保留 Git 冲突现场。中止后恢复复习日志失败时明确返回失败，并保留快照路径。
- 评分撤销改为追加 type=undo、undo_event_id 指向原评分的事件。读取、缓存与 FSRS 重放过滤作废评分，Git 合并/中止不再使其复活。原评分事件仍参与重试去重。各设备需使用支持撤销事件的新版本。
- 撤销尚未完成时禁用评分及暂停，包含快捷键；按原卡片位置恢复队列，并在离开页面时保护尚未完成的撤销。
- 编辑器增加引用续行、空引用结束；macOS 桌面测试保存快捷键使用 Cmd+S。
- 今日页复习入口与快速待办框增加 12px 间距。
- 历史对比的纯新增/纯删除也遵守 2000 行上限。

## Windows 等待根因与最终修复

定向诊断发现：Electron 测试进程的异步 waitForFunction 返回 handle=false，却已经继续执行。Playwright 1.62.1 的谓词检查不等待 Promise；async 谓词返回的 Promise 被立即当成真值，随后才解析为 false。独立代理用最小 Electron 页面验证：async()=>false 约 22ms 即返回 false，同步()=>false 则正确等到超时。

新增测试侧 waitForApi，在 Node 侧等待每次 fetch 完成并检查响应结果，再决定重试。替换全部八处索引等待和一处冲突状态等待；加入未就绪响应继续轮询及超时诊断回归。此问题属于测试等待语义，未据此改写产品 Git 状态。

原 v0.3.0 发布流程已取消，未发布公开安装包；最终版本为 v0.3.1，继续由真实 Windows/macOS 及打包测试验证。

## 目录键盘高亮修复

v0.3.1 的主分支 Linux、macOS 和 Windows 全部通过；发布 Mac 中的目录测试出现一次超时。独立代理先复现了“PageUp 后立即脚本滚动”可能互相覆盖的测试竞态，再通过等待键盘滚动完成后重测，确认另有产品缺陷：焦点留在 role=tab 时，第二标题已到距顶 24px，高亮仍锁在末章，滚轮解除锁后立即恢复。

产品现在只跳过编辑控件以及按钮/标签的 Space 激活；已被标签消费的导航键通过 defaultPrevented 保护，未消费的正文滚动键释放章节锁。桌面回归明确将焦点置于目录标签，并等待 PageUp 的 scrollend 后再测试独立的程序滚动，避免掩盖高亮问题。原两个未发布标签保留，最终版本更新为 v0.3.2。
