# Workstation Mini 0.4.1

- 新增重名卡片、删除已移走的卡片时，原有卡片保留自己的评分与到期时间。编辑期间遇到外部修改会提示版本冲突。
- 恢复旧草稿并保存时，如果原编辑器又保存了新版草稿，新版仍可在「历史与草稿」找到。退出或切换资料库时会等待已经开始的保存完成。
- 扫描意外中断后，启动或执行「重新扫描索引」可以补齐反链。仅用 CR 换行的旧笔记也能正确识别公式块之后的双链。首次升级会从笔记重建本机索引。
- 同步维护规则文件时检查文件类型。本地恢复会检查备份对 Git 对象库的依赖，遇到无法随备份一起迁移的对象库会给出提示。
- 本次安装包也包含 0.4.0 以来的复习轮次与侧栏位置保留、重复建卡确认，以及桌面弹窗、待办、粘图和 Markdown 兼容性修复。

**安装**　Windows x64 使用 `workstation-mini-0.4.1-setup.exe`，Apple Silicon Mac 使用 `workstation-mini-0.4.1-mac-arm64.dmg`。下载校验值见 `SHA256SUMS.txt`。可直接在现有资料库上手动升级，多设备建议一起升级。
