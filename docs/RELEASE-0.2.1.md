# Workstation Mini 0.2.1

- 统一主窗口、设置窗口与资料库恢复窗口的配色、字号、圆角及控件尺寸，调整浅色画布与深色主按钮视觉。
- 首次启动改为欢迎页，提供「创建新资料库」「打开现有资料库」和「从备份恢复」三个入口。
- 稳定各页面的内容左边缘，精简今日页与复习页的重复信息，改善编辑页标题、版本历史及搜索摘要展示。
- 修复搜索摘要数字高亮破坏公式、HTML 实体被截断以及正文标题前缀被误删的问题。
- 统一侧栏底部图标间距与矮窗口布局，修复设置页输入框被相邻区域拉伸的问题。

资料库格式保持不变，无需手动迁移。看板状态、计划日期与卡片暂停/恢复操作会在鼠标悬停或键盘聚焦时显示；Windows 与 Linux 下可按 `Alt` 呼出菜单栏。

**安装与升级：** Windows x64 使用 `setup.exe`，Apple Silicon Mac 使用 `mac-arm64.dmg`；校验值见 `SHA256SUMS.txt`。Windows 安装包未配置代码签名，macOS 使用 ad-hoc 签名且未经 Apple 公证。Mini 版不支持自动更新，请手动下载安装。

完整变更记录见 `CHANGELOG.md`。
