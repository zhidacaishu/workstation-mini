# Workstation Mini 0.4.0

- 打开「复习」，点击右上角「新建卡片」即可直接填写正反面并选择卡组。在答题途中建卡，保存后可继续当前题目。Windows 用 Ctrl+Enter 保存，macOS 用 ⌘+Enter。
- 月历选日和跨月时局部更新。同月选日保留滚动位置，重选「今天」保留未保存的备注，连续快速选日以最后一次为准。
- 侧栏图标放大，搜索与主导航的间距增加。笔记正文和复习说明随可用宽度排版，移除笔记「舒适行宽」开关。
- 应用内确认框跟随深浅主题。修复粘贴的图片尚未上传时保存笔记可能写入占位符的问题，并改善草稿恢复和卡片身份保留。

**安装**　Windows x64 下载 `workstation-mini-0.4.0-setup.exe`，Apple Silicon Mac 下载 `workstation-mini-0.4.0-mac-arm64.dmg`。两个安装包的 SHA-256 校验值见 `SHA256SUMS.txt`。

本版本沿用现有资料库格式，可直接手动升级。Windows 安装包未配置代码签名，macOS 安装包使用 ad-hoc 签名，未经 Apple 公证。
