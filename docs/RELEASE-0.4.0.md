# Workstation Mini 0.4.0

- 打开「复习」页并点击右上角「新建卡片」，可直接填写正反面并选择卡组；答题途中建卡并保存后，保留当前题目与翻面状态。保存快捷键为 Windows `Ctrl+Enter`、macOS `⌘+Enter`。
- 月历切换日期与月份时改为局部更新：同月选日保留滚动位置，重选「今天」保留未保存备注，连续快速选日以最后一次选择为准。
- 放大侧栏图标并增加搜索与主导航之间的间距；笔记正文与复习说明随可用宽度排版，移除笔记「舒适行宽」开关。
- 应用内确认框跟随深浅主题；修复粘贴图片尚未上传完成时保存笔记可能写入占位符的问题，并改进草稿恢复与卡片身份保留。

**安装与升级：** Windows x64 下载 `workstation-mini-0.4.0-setup.exe`，Apple Silicon Mac 下载 `workstation-mini-0.4.0-mac-arm64.dmg`；两个安装包的 SHA-256 校验值见 `SHA256SUMS.txt`。本版本沿用现有资料库格式，可直接手动升级。Windows 安装包未配置代码签名，macOS 安装包使用 ad-hoc 签名且未经 Apple 公证。
