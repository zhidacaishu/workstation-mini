# Workstation Mini：范围与取舍

`workstation-mini` 面向博士后半段、同时准备实习的 AI 研究者。它把每天最常用的输入（想法、任务、复习卡片）压缩到一个本地优先的工作循环：**记录 → 行动 → 回忆 → 产出**。

## 明确移除的功能

以下模块从 Mini 的导航、路由和运行时依赖中移除，不再维护兼容入口：

- Zotero 同步（题录、标注、库状态）
- PDF 解析、PDF 全文检索、PDF 问答
- 独立日记页、历年今日、独立回顾页和多套回顾模板
- 图谱可视化、自动知识质量分析、自动相似建议；只读资料库健康诊断保留
- 影子跟读、字幕、音频转写
- 博客 MDX 发布、独立投稿流程
- 教材进度看板
- 未接入的 AI 生成/问答、API key 配置与模板选择器
- 远程大文件补齐及当前资料库大文件修复；本地备份中的普通文件仍完整复制
- 错题本、错因统计、错题转卡片、外部写作检查器和 Python 路径配置（不删除已有日志和卡组）

PDF 与文献可通过普通 Markdown 链接引用，既有附件文件保持原样；日记内容可直接写在研究笔记中；发布通过复制 Markdown 完成。Mini 不提供附件上传或专属预览流程，避免维护高耦合集成。

## Mini 保留的核心工作流

| 工作流 | Mini 能力 | 设计理由 |
| --- | --- | --- |
| 捕捉 | Markdown 研究笔记、草稿保护、全文检索、双链 | 研究想法必须低摩擦落盘，纯文本可被 Obsidian/脚本继续使用 |
| 执行 | 今日工作区与统一计划（列表／月历、待办到期日、项目期限、当天备注） | 把“下一步动作”放在同一入口，减少在备忘录、日历、任务应用间切换 |
| 记忆 | 卡片、挖空卡、划词建卡、FSRS 间隔重复、复习记录 | 直接回应“最容易忘记知识点”的痛点，且成本低于完整知识图谱 |
| 研究产出 | 研究项目与实验笔记，记录问题、证据、结论和下一步 | 连接论文/实验与实习准备，形成可追踪的交付物 |
| 可恢复性 | 本地历史、草稿恢复、可重建 SQLite 索引、Git 文本同步 | AI 工作流经常生成大量中间版本，恢复能力比复杂分析更重要 |

## 日常使用建议

1. **随手记录**：所有新想法先进入一条带主题和下一步的 Markdown 笔记，不再区分“日记/灵感/阅读笔记”多个入口。
2. **从今日页开始**：今日页显示最多两个研究项目、四条待办、待复习卡片和最近笔记；完整任务队列与筛选留在计划页。
3. **把遗忘变成卡片**：遇到不会或容易混淆的概念立即划词建卡；FSRS 只安排必要的复习量。
4. **每周一次人工回顾**：用搜索和任务筛选检查未完成事项、最近的研究结论和实习准备，不维护额外的回顾数据库。
5. **产出优先**：每个研究项目都保留“问题—证据—下一实验—可展示结果”四段式笔记，方便转成论文段落、面试项目说明或简历 bullet。

## 当前时代的边界

- **本地优先、不依赖模型**：不提供内置 AI 调用或 API key 配置，记录、任务和复习不需要外部模型服务。
- **一个计划工作区**：旧待办、月历和截止事项 URL 保留兼容访问，统一使用计划页，不维护旧模板。
- **不做自动代理**：Mini 不自动发送邮件、投稿或操作代码仓库；资料库 Git 同步仅在显式启用后定时拉取、提交和推送，恢复流程不写入远端。
- **统一桌面体验**：主窗口、设置和恢复使用「石墨」视觉、窄图标侧栏、打包字体（Geist / 思源黑体）与完整的深浅两套主题；保留键盘焦点和减少动效支持。
- **数据可迁移**：Markdown、JSONL 与附件目录保持公开格式，未来可迁移到 Obsidian、脚本或其他 AI 工具。

## 验收标准

- 首次启动后无需配置 Zotero、PDF、音频或博客服务即可完成“记录 → 任务 → 复习”。
- 月历按日期展示备注与截止事项，可编辑、清空备注，保存为普通 Markdown。
- 设置不包含 AI 或远程大文件服务配置，笔记、检索、任务、日历、卡片、复习和资料库恢复流程仍可用。
- `npm test` 与桌面冒烟测试通过，安装包名称和应用标识与 `workstation-mini` 区分。
