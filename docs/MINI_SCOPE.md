# Workstation Mini：范围与取舍

`workstation-mini` 面向博士后半段、同时准备实习的 AI 研究者。它把每天最常用的输入（想法、任务、复习卡片）压缩到一个本地优先的工作循环：**记录 → 行动 → 回忆 → 产出**。

## 明确移除的功能

以下模块从 Mini 的导航、路由和运行时依赖中移除，不再维护兼容入口：

- Zotero 同步（题录、标注、库状态）
- PDF 解析、PDF 全文检索、PDF 问答
- 独立日记页、历年今日、独立回顾页和多套回顾模板
- 图谱可视化、知识库体检、自动相似建议
- 影子跟读、字幕、音频转写
- 博客 MDX 发布、独立投稿流程
- 教材进度看板

PDF 与文献仍可作为普通附件或 Markdown 链接保存；日记内容可直接写在研究笔记中；发布通过复制 Markdown 完成。这样可以保留资料可迁移性，同时避免维护高耦合集成。

## Mini 保留的核心工作流

| 工作流 | Mini 能力 | 设计理由 |
| --- | --- | --- |
| 捕捉 | Markdown 研究笔记、模板、草稿保护、全文检索、双链 | 研究想法必须低摩擦落盘，纯文本可被 Obsidian/脚本继续使用 |
| 执行 | 今日工作区、待办、截止日期、轻量日历/时间块、系统提醒 | 把“下一步动作”放在同一入口，减少在备忘录、日历、任务应用间切换 |
| 记忆 | 卡片、挖空卡、划词建卡、FSRS 间隔重复、复习记录 | 直接回应“最容易忘记知识点”的痛点，且成本低于完整知识图谱 |
| 研究产出 | 研究看板、写作检查、错题记录与错题转卡片 | 连接论文/实验与实习准备，形成可追踪的交付物 |
| 可恢复性 | 本地历史、草稿恢复、可重建 SQLite 索引、Git 文本同步 | AI 工作流经常生成大量中间版本，恢复能力比复杂分析更重要 |
| AI 辅助（可选） | 对本地 Markdown 做定向检索/问答；明确展示引用来源 | 让模型帮助理解和复习，但不把知识真源交给模型或云端 |

## 日常使用建议

1. **随手记录**：所有新想法先进入一条带主题和下一步的 Markdown 笔记，不再区分“日记/灵感/阅读笔记”多个入口。
2. **每天只看今日页**：今日页显示三件最重要的下一步、到期任务和待复习卡；其余内容留在检索中。
3. **把遗忘变成卡片**：遇到不会或容易混淆的概念立即划词建卡；FSRS 只安排必要的复习量。
4. **每周一次人工回顾**：用搜索和任务筛选检查未完成事项、最近的研究结论和实习准备，不维护额外的回顾数据库。
5. **产出优先**：每个研究项目都保留“问题—证据—下一实验—可展示结果”四段式笔记，方便转成论文段落、面试项目说明或简历 bullet。

## 当前时代的边界

- **本地优先、模型可替换**：AI 服务只作为可选加速器；API 不可用时，记录、任务和复习仍完整可用。
- **引用可追溯**：AI 生成的摘要或答案必须回链到笔记路径和段落，避免把模型记忆当作事实。
- **人机协作而非自动代理**：Mini 不自动发送邮件、投稿、推送代码或修改远端资料；这些高影响动作由用户显式完成。
- **数据可迁移**：Markdown、JSONL 与附件目录保持公开格式，未来可迁移到 Obsidian、脚本或其他 AI 工具。

## 验收标准

- 首次启动后无需配置 Zotero、PDF、音频或博客服务即可完成“记录 → 任务 → 复习”。
- 导航中不出现已移除模块；访问旧路径返回明确的“Mini 未提供该功能”页面，而不是加载半残界面。
- 关闭可选 AI 配置后，笔记、检索、任务、日历、卡片、复习和恢复流程仍可用。
- `npm test` 与桌面冒烟测试通过，安装包名称和应用标识与 `workstation-mini` 区分。
