# Workstation Mini 功能边界

Workstation Mini 面向研究型 AI 博士生的日常闭环：捕捉 → 检索 → 计划 → 复习 → 练习。资料库仍以本地 Markdown 为唯一真源，SQLite 只做可重建索引。

## 保留的最小闭环

| 区域 | Mini 行为 | 取舍依据 |
| --- | --- | --- |
| 今日 | 聚合今天的任务、截止日、待复习卡片和最近笔记 | 每次打开都有下一步，减少上下文切换 |
| 笔记 | Markdown 新建（先写标题，默认进 `inbox/`）、编辑、删除、版本/草稿恢复（含卡组文件），支持 wikilink 与反链；列表分页 | 研究材料的长期可迁移底座 |
| 搜索 | 中文全文检索、按栏目/标签筛选、最近笔记 | 找回被遗忘的知识点比自动推荐更可靠 |
| 计划 | 一个入口、列表／月历切换，完成待办、调整到期日、查看项目期限与编辑当天备注；阅读页直接勾选 | 把研究工作和实习准备放进同一队列 |
| 记忆 | Markdown 卡组、划词建卡、应用内改卡/删卡/暂停/挪卡组、FSRS 间隔复习、「忘了」本轮重学、设备复习日志 | 直接解决“知道但记不住” |
| 同步 | Git 文本同步（可选）：先提交再变基，遵循显式推送配置，冲突时可在设置中逐文件选边或使用 Git 处理；统一 LF 换行；启动前可恢复资料库 | 多设备使用仍保持可控和可回滚，保留 Git 冲突现场，不自动覆盖任一版本 |
| 排障 | 只读资料库健康诊断，汇总索引、复习日志与 Git 状态 | 故障时保留可操作的诊断入口，不做知识质量评分 |

## 明确移除

下列入口、路由、后台任务和设置字段在 Mini 中不提供：

- Zotero 题录/标注同步及其 PDF 解析缓存（MinerU）。
- PDF 全文检索、PDF 预览、基于 PDF 的资料库问答。
- 独立日记页、历年今日、周/月多套回顾页；保留今日聚合，普通 Markdown 笔记承载反思。
- 双链图谱、知识依赖图、自动知识质量分析、自动相似笔记/链接建议；只读资料库健康诊断保留。
- 错题本、错因统计、错题转卡片与外部写作检查器及其配置；已有日志和卡组文件保持不变。
- 影子跟读、音频字幕播放器、本地转写。
- 博客 MDX 发布、独立投稿追踪、教材进度看板；统一用普通待办和标签表达。
- 旧审稿意见解析与回复稿导出、章节习题完成度派生及看板进度条、未接入的复习负荷预测；保留已有笔记字段与复习日志。
- 未接入的 AI 生成/问答、API key 设置及 SDK 依赖；不提供模板选择器。
- 独立待办、月历和截止事项模板；旧 URL 仍兼容访问统一计划页。
- 通用附件上传。编辑器支持粘贴或拖入 PNG、JPEG、GIF、WebP 图片，每张最多 15 MB。其它媒体放入资料库目录后可用相对路径引用。
- 远程大文件下载补齐和当前资料库大文件修复；保留 Git 克隆、本地备份复制、索引验证、失败重试和安全激活，不删除来源中的普通文件。
- 自动更新：安装包通过 GitHub Releases 手动下载安装，打包配置不生成更新清单。
- 音频、视频嵌入播放：`![[录音.mp3]]` 显示为链接，点击后用系统默认应用打开，页面里不内嵌播放器。
- `/section/:section` 页面：用 `/search?section=` 的筛选代替。

移除功能必须从三处同时清理：导航入口、HTTP 路由、设置/配置字段。残留的底层纯函数可以暂时保留给迁移和旧资料读取，但不能被 Mini UI 或默认启动流程调用。

## 设计约束

1. 一个入口：首页只呈现“现在做什么”和“接下来复习什么”，避免多个回顾页重复统计。
2. 外部服务边界：不提供内置 AI、文献集成或远程大文件服务；Git 自动同步仅在显式启用后运行，恢复只读取来源、不提交或推送。
3. 低维护成本：优先使用现有 Express/EJS 和 Markdown 数据结构，不引入新的数据库表或云端账号体系。卡片暂停、固定 ID 这类状态写在卡组 Markdown 的机器注释行里，不另建存储。
4. 可迁移：Mini 资料库可被完整版打开；删除的模块只影响对应页面，不修改已有 Markdown、卡组和复习日志。
5. 桌面优先：仅维护 Electron 桌面布局（主窗口最小 900px、设置窗口最小 760px）；不维护移动导航、手机断点和窄屏专属交互。保留桌面窗口缩放、明暗主题和减少动效支持。
6. 视觉一致：主窗口、设置和恢复共用「石墨」视觉与打包字体（Geist / Geist Mono / 思源黑体），深浅两套主题完整对应；代码保留等宽字体，阅读页随窗口宽度展开并保留左右边距，导航、键盘焦点与选中状态不能只依赖颜色表达。

## 验收清单

- 启动后可创建/打开资料库，首页能显示任务、截止日和待复习数量。
- 可新建/编辑/搜索 Markdown 笔记，外部编辑后索引能更新，历史/草稿可恢复；有未保存修改时离开页面会弹出「离开 / 留下」。
- 可在计划列表或月历选中日直接完成任务、调整到期日；未安排日期任务有独立筛选，项目期限不作为任务勾选。
- 可添加卡片并完成 FSRS 复习，复习日志可选 Git 同步；可在应用内修改、暂停、挪动和删除卡片，改正面后复习记录仍在。
- 在笔记阅读页勾选待办后，原文那一行变成 `- [x]`，今日页和计划页同步更新。
- 月历按日期展示备注与截止事项，可编辑、清空备注，保存为普通 Markdown。
- 冲突选边前保留文件现场。笔记与卡组的完整内容进本机历史，其它文件按原始字节留副本。选择手工合并结果时，仍有明确标记会提示所在行。设置页可继续或中止当前合并或变基。
- 显式要求同名推送时，遇到异名上游会停止推送并说明原因。复习同步只更新已核验的目标分支。
- 笔记历史写入失败时，保存停止，原文件与编辑器新稿均可检查或重试。
- Windows 询问是否结束会话时，对未保存的笔记、卡片和设置提供保存、放弃和返回选项。
- npm test 与 npm run test:desktop 通过；至少运行一次 npm start 或 npm run dev 完成桌面冒烟验证。
