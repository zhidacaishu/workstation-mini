# Workstation Mini 功能边界

Workstation Mini 面向研究型 AI 博士生的日常闭环：捕捉 → 检索 → 计划 → 复习 → 练习。资料库仍以本地 Markdown 为唯一真源，SQLite 只做可重建索引。

## 保留的最小闭环

| 区域 | Mini 行为 | 取舍依据 |
| --- | --- | --- |
| 今日 | 聚合今天的任务、截止日、待复习卡片和最近笔记 | 每次打开都有下一步，减少上下文切换 |
| 笔记 | Markdown 新建、编辑、删除、版本/草稿恢复，支持 wikilink 与反链 | 研究材料的长期可迁移底座 |
| 搜索 | 中文全文检索、按栏目/标签筛选、最近笔记 | 找回被遗忘的知识点比自动推荐更可靠 |
| 计划 | Markdown 待办、完成/延期与截止日 | 把研究工作和实习准备放进同一队列 |
| 记忆 | Markdown 卡组、划词建卡、FSRS 间隔复习、设备复习日志 | 直接解决“知道但记不住” |
| 错题 | 写作检查/练习记录，错因可转成复习卡 | 将失败转为下一次可检索的训练材料 |
| 同步 | Git 文本同步（可选），启动前可恢复资料库 | 多设备使用仍保持可控和可回滚 |

## 明确移除

下列入口、路由、后台任务和设置字段在 Mini 中不提供：

- Zotero 题录/标注同步及其 PDF 解析缓存（MinerU）。
- PDF 全文检索、PDF 预览、基于 PDF 的资料库问答。
- 独立日记页、历年今日、周/月多套回顾页；保留今日聚合，普通 Markdown 笔记承载反思。
- 双链图谱、知识依赖图、知识库体检、自动相似笔记/链接建议。
- 影子跟读、音频字幕播放器、本地转写。
- 博客 MDX 发布、独立投稿追踪、教材进度看板；统一用普通待办和标签表达。

移除功能必须从三处同时清理：导航入口、HTTP 路由、设置/配置字段。残留的底层纯函数可以暂时保留给迁移和旧资料读取，但不能被 Mini UI 或默认启动流程调用。

## 设计约束

1. 一个入口：首页只呈现“现在做什么”和“接下来复习什么”，避免多个回顾页重复统计。
2. 显式动作：不会在后台自动调用外部 AI、文献服务或上传服务；需要时由用户手动触发并能看到输入/输出。
3. 低维护成本：优先使用现有 Express/EJS 和 Markdown 数据结构，不引入新的数据库表或云端账号体系。
4. 可迁移：Mini 资料库可被完整版打开；删除的模块只影响对应页面，不修改已有 Markdown、卡组和复习日志。
5. 渐进式发布：先提供本地开发和测试启动；桌面打包沿用 Electron，确认路由白名单和数据迁移后再生成安装包。

## 验收清单

- 启动后可创建/打开资料库，首页能显示任务、截止日和待复习数量。
- 可新建/编辑/搜索 Markdown 笔记，外部编辑后索引能更新，历史/草稿可恢复。
- 可在任务页完成或延期任务，并维护截止日期。
- 可添加卡片并完成 FSRS 复习，复习日志可选 Git 同步。
- 访问 library、ask、graph、health、shadowing、publish、board/submission、board/chapter 等已移除地址时返回明确的 404，而不是渲染空页面。
- npm test 通过；至少运行一次 npm start 或 npm run dev 完成桌面冒烟验证。
