# Workstation Mini 功能边界

Workstation Mini 面向研究型 AI 博士生的日常工作闭环：**捕捉 → 检索 → 计划 → 复习 → 练习**。资料库以本地 Markdown 作为唯一数据真源，SQLite 仅作可随时重建的派生索引。

## 保留的最小闭环

| 区域 | Mini 行为 | 取舍依据 |
| --- | --- | --- |
| 今日 | 聚合当日任务、截止日、待复习卡片与最近笔记 | 每次打开即明确下一步，减少上下文切换 |
| 笔记 | Markdown 新建（先填标题，默认存至 `inbox/`）、编辑、删除、版本与草稿恢复（含卡组文件），支持双链（wikilink）与反链；列表分页 | 研究材料的长期可迁移底座 |
| 搜索 | 中文全文检索、按栏目/标签筛选、最近笔记 | 主动找回已遗忘的知识点比自动推荐更可靠 |
| 计划 | 单一入口与列表/月历切换，支持完成待办、调整到期日（含精确一键撤销与行内还原）、查看项目期限与编辑当天备注；阅读页直接勾选待办并实时更新逾期角标 | 将研究工作与实习准备纳入同一队列 |
| 记忆 | Markdown 卡组、划词建卡（自动补全已有卡组）、应用内改卡/删卡/就地暂停与撤销/挪卡组、FSRS 间隔复习、「忘了」本轮重学、按设备区分的复习日志 | 直接解决“知道但记不住”的问题 |
| 同步 | 可选 Git 文本同步：先提交再变基，遵循显式推送配置，冲突时可在设置中逐文件选边或使用 Git 手工处理；统一 LF 换行；启动前支持恢复资料库 | 多设备协同仍保持可控与可回滚；保留 Git 冲突现场，不自动覆盖任一版本 |
| 排障 | 只读资料库健康诊断，汇总索引、复习日志、断链/同名歧义双链与 Git 状态 | 故障时提供可操作的诊断入口，不做知识质量评分 |

## 明确移除

下列入口、路由、后台任务及设置字段在 Mini 版中不予提供：

- Zotero 题录与标注同步，及其 PDF 解析缓存（MinerU）。
- PDF 全文检索、PDF 预览及基于 PDF 的资料库问答。
- 独立日记页、历年今日及周/月多套回顾页；保留「今日」聚合视图，使用普通 Markdown 笔记承载反思。
- 双链图谱、知识依赖图、自动知识质量分析及自动相似笔记/链接建议；保留只读资料库健康诊断。
- 错题本、错因统计、错题转卡片与外部写作检查器及其配置；既有日志与卡组文件保持不变。
- 影子跟读、音频字幕播放器及本地转写。
- 博客 MDX 发布、独立投稿追踪及教材进度看板；统一以普通待办与标签管理。
- 旧审稿意见解析与回复稿导出、章节习题完成度派生及看板进度条、未接入的复习负荷预测；保留已有笔记字段与复习日志。
- 未接入的 AI 生成/问答、API Key 设置及 SDK 依赖；不提供模板选择器。
- 独立待办、月历与截止事项模板；旧 URL 仍兼容跳转至统一计划页。
- 通用附件上传。编辑器支持粘贴或拖入 PNG、JPEG、GIF、WebP 图片，单张上限 15 MB；其余媒体文件放入资料库目录后可通过相对路径引用。
- 远程大文件下载补齐与当前资料库大文件修复；保留 Git 克隆、本地备份复制、索引验证、失败重试与安全激活，不删除来源目录中的普通文件。
- 自动更新：安装包通过 GitHub Releases 手动下载安装，打包配置不生成更新清单。
- 音频、视频内嵌播放：`![[录音.mp3]]` 渲染为链接，点击后由系统默认应用打开，页面内不嵌入播放器。
- `/section/:section` 页面：改由 `/search?section=` 筛选替代。

移除功能时必须从三处同步清理：**导航入口**、**HTTP 路由**与**设置/配置字段**。残留的底层纯函数可暂留用于迁移与旧资料读取，但不得被 Mini UI 或默认启动流程调用。

## 设计约束

1. **单一入口**：首页仅呈现「当前要做什么」与「接下来复习什么」，避免多套回顾页造成统计重复。
2. **外部服务边界**：不内置 AI 服务、文献集成或远程大文件服务；Git 自动同步仅在用户显式启用后运行；资料库恢复仅读取来源，不执行提交或推送。
3. **低维护成本**：沿用现有 Express/EJS 与 Markdown 数据结构，不引入新的数据库表或云端账号体系。卡片暂停、固定 ID 等状态均写入卡组 Markdown 的机器注释行，不另建存储。
4. **可迁移性**：Mini 资料库可由完整版直接打开；被精简的模块仅移除对应页面，不改动既有 Markdown、卡组与复习日志。
5. **桌面优先**：应用运行于 Electron，主窗口、设置和恢复窗口最小宽度均为 360 px。布局适应手机尺寸视口，支持窗口缩放、明暗主题及减少动态效果。
6. **视觉一致**：主窗口、设置窗口与恢复窗口共用「石墨」视觉体系及本地打包字体（Geist / Geist Mono / 思源黑体），深浅两套主题完整对应；代码保留等宽字体，阅读页随窗口宽度展开并保留左右边距；导航、键盘焦点与选中状态不得仅依赖颜色区分。

## 验收清单

- 启动后可创建或打开资料库，首页正确展示当日任务、截止日与待复习卡片数。
- 可新建、编辑与搜索 Markdown 笔记，外部编辑后索引能及时更新，历史版本与草稿可恢复；存在未保存修改时离开页面会弹出「离开 / 留下」确认框。
- 可在计划列表或月历选中日直接完成任务、调整到期日；未安排日期的任务提供独立筛选，项目期限不作为任务勾选。
- 可添加卡片并完成 FSRS 复习，复习日志支持可选 Git 同步；支持在应用内修改、暂停、移动与删除卡片，修改正面后复习记录保持不丢。
- 在笔记阅读页勾选待办后，原文对应行更新为 `- [x]`，「计划」入口的逾期角标同步更新，今日页与计划页同步刷新；待办完成、改期与卡片暂停均支持一键撤销。
- 月历按日期展示备注与截止事项，支持编辑与清空备注，并以普通 Markdown 保存。
- 冲突选边前完整保留文件现场：笔记与卡组的完整内容存入本机历史，其余文件按原始字节保留副本；选择手工合并结果时，若仍存在明确冲突标记则提示所在行；设置页支持继续或中止当前合并/变基。
- 显式配置同名推送规则时，遇到异名上游会停止推送并说明原因；复习同步仅更新已核验的目标分支。
- 笔记历史写入失败时停止保存，磁盘原文件与编辑器新稿均保留以供检查或重试。
- Windows 询问是否结束会话时，对未保存的笔记、卡片与设置提供保存、放弃和返回选项。
- `npm test` 与 `npm run test:desktop` 全部通过，且至少运行一次 `npm start` 或 `npm run dev` 完成桌面冒烟验证。
