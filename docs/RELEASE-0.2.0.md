# Workstation Mini 0.2.0

- 新增卡片应用内编辑、移动、删除、暂停与本轮重学，以及按标题新建笔记、阅读页直接勾选待办功能，并优化上手引导、版本历史与草稿体验。
- 发生 Git 冲突时立即停止同步并保留现场，由用户手工解决或在设置中中止；不再自动采用远端、生成冲突副本或继续推送。
- 修复同步与跨文件写入死锁、卡片 ID 重复导致复习记录串用、草稿保存失败后重载丢失内容、拉取失败误报成功以及退出同步超时等问题。
- 修复安装包启动失败问题，保留三平台回归测试及 Windows / macOS 打包态桌面应用验证。

**安装与升级：** Windows x64 使用 `setup.exe`，Apple Silicon Mac 使用 `mac-arm64.dmg`；校验值见 `SHA256SUMS.txt`。Windows 安装包未配置代码签名，macOS 使用 ad-hoc 签名且未经 Apple 公证。Mini 版不支持自动更新，请手动下载安装。多台设备建议同步升级；手工解决 Git 冲突并完成变基后，请重启应用再继续同步。

完整变更记录见 `CHANGELOG.md`。
