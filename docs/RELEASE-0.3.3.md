# Workstation Mini 0.3.3

- 修复原生跨页过渡期间按钮、链接与保存点击偶发失效的问题：工作区改用 140 ms 普通 CSS 淡入，侧栏保持稳定，过渡期间可正常操作，且继续支持系统「减少动态效果」设置。
- 新增延长动画期间的真实坐标点击回归测试，覆盖复习入口、翻面按钮与编辑器保存。
- 包含 0.3.2 的编辑器增强、快速待办、复习撤销、历史对比、同步冲突处理及数据保全修复。

**安装与升级：** Windows x64 使用 `setup.exe`，Apple Silicon Mac 使用 `mac-arm64.dmg`；校验值见 `SHA256SUMS.txt`。Windows 安装包未配置代码签名，macOS 使用 ad-hoc 签名且未经 Apple 公证。Mini 版不支持自动更新，请手动下载安装。多台设备使用时请一同升级，以确保正确识别复习撤销事件。

完整变更记录见 `CHANGELOG.md`。
