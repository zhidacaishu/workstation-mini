Workstation Mini 0.3.1

- 编辑器支持列表、待办与引用续行、Tab 缩进、双链笔记补全、图片粘贴或拖入，以及宽窗口下的实时预览。
- 代码块按标注语言高亮，阅读页支持复制代码和舒适行宽；改善公式、挖空答案、摘要与日期展示。
- 今日和计划列表可以直接添加待办；历史页新增逐行差异预览；健康页列出断链来源。
- 复习支持撤销上一张评分。撤销记录随日志同步，冲突处理后仍有效。
- Git 同步遇到冲突时，可在设置中逐个文件选择远端、本机或已手工合并的内容；未采用的笔记和卡组版本保存在本机历史。
- 中止 Git 操作前，先持久备份未提交与已暂存修改。备份失败时保留冲突现场，避免撤掉尚未保全的内容。
- 修复复习同步、写入闸门、网络超时、YAML 属性区、大小写索引与草稿清理等可靠性问题。
- 修复图片上传乱序及上传中保存临时链接；撤销评分可安全重试。冲突合并和中止恢复增加超限、符号链接及写入失败保护。

多设备使用时请一同升级。新版本新增了撤销事件，旧版本不会识别撤销语义；笔记和卡组仍是 Markdown，索引可随时重建。

安装包：Windows x64 使用 setup.exe；Apple Silicon Mac 使用 mac-arm64.dmg。SHA256SUMS.txt 提供校验值。

Windows 安装包未配置代码签名；macOS 为 ad-hoc 签名，未经 Apple 公证。Mini 不自动更新，请手动下载安装。

完整变更见 CHANGELOG.md。

本轮安装包以 v0.3.1 发布。v0.3.0 的发布因验收未通过取消，未生成公开安装包。桌面测试已修正异步请求等待，避免在索引或 Git 状态尚未就绪时提前继续。
