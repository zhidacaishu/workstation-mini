# Workstation Mini 0.3.1

- 编辑器支持列表、待办与引用块续行、`Tab` 缩进、双链笔记补全、图片粘贴或拖入，以及宽窗口下的右侧实时预览。
- 代码块支持按标注语言高亮，阅读页新增代码复制与舒适行宽切换；优化数学公式、挖空答案、搜索摘要与日期展示。
- 今日页与计划列表支持快速添加待办；历史页新增逐行差异预览；健康页列出断链来源笔记。
- 复习支持撤销上一张评分；撤销记录随复习日志同步，经冲突处理后依然有效。
- Git 同步发生冲突时，可在设置中逐文件选择远端版本、本机版本或已手工合并的内容；未采用的笔记与卡组版本保存在本机历史中。
- 中止 Git 操作前预先持久备份未提交与已暂存修改；若备份失败则保留冲突现场，避免撤消尚未保全的内容。
- 修复复习同步、写入闸门、网络超时、YAML 属性区解析、大小写索引与草稿清理等可靠性问题。
- 修复图片上传乱序及上传期间保存写入临时链接的问题；撤销评分支持安全重试，冲突合并与中止恢复新增超限、符号链接及写入失败保护。

**安装与升级：** Windows x64 使用 `setup.exe`，Apple Silicon Mac 使用 `mac-arm64.dmg`；校验值见 `SHA256SUMS.txt`。Windows 安装包未配置代码签名，macOS 使用 ad-hoc 签名且未经 Apple 公证。Mini 版不支持自动更新，请手动下载安装。多台设备协同使用时请一同升级：本版本新增了撤销事件，旧版本无法识别撤销语义；笔记与卡组仍为 Markdown，索引可随时重建。

完整变更记录见 `CHANGELOG.md`。

> 本轮安装包以 `v0.3.1` 发布。`v0.3.0` 因验收未通过取消发布，未生成公开安装包。桌面测试已修正异步请求等待逻辑，避免在索引或 Git 状态尚未就绪时提前继续。
