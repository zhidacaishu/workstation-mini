# Workstation Mini 0.5.0

- **统一动效与交互体验升级**：主窗口、设置窗口、恢复/欢迎窗口与确认弹窗共用同一套动效曲线、节奏与可打断的纯 GPU 动效内核，支持看板跨列 FLIP 移动、复习高频方向切卡与键盘评分回响、月历方向切月、侧栏与主题切换滑动指示器、编辑器拖图高亮、Toast 悬停/聚焦暂停及平滑退场，并完整尊重系统「减少动态效果」设置（含 `dialog::backdrop` 与运行中切换）。
- **Windows 关机与注销未保存保护**：系统关机、重启或注销时，若笔记、卡片或设置存在未保存编辑，将提示保存、放弃或返回编辑；多窗口未保存更改依次处理，保存失败或超时后保留编辑现场。
- **Git 显式推送与三方冲突完整备份**：完整同步与退出推送严格遵循显式推送配置（如 `push.default=simple` 下的异名上游分支提示并中止）；冲突选边前完整备份笔记与卡组现场（含三方合并共同祖先段中的手工改动），其余文件保留原始字节副本，残留冲突标记时提示行号。
- **本机历史写入失败保护**：覆盖笔记前若本机历史版本落盘失败，将停止保存并保留磁盘原文与编辑器新稿，恢复磁盘空间或写入权限后可安全重试。
- **中英文项目文档**：仓库默认 `README.md` 提供英文说明，并同步维护完整中文说明 `README.zh-CN.md` 与界面预览截图。

**安装与升级：** Windows x64 使用 `workstation-mini-0.5.0-setup.exe`，Apple Silicon Mac 使用 `workstation-mini-0.5.0-mac-arm64.dmg`；下载校验值见 `SHA256SUMS.txt`。可直接在现有资料库上手动升级，多台设备建议同步升级。
